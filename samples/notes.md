# 现场记录：一片黑到底算几块

时间：2026-09-28
在场：老周、小林

同一张二值网格图，黑的地方看着是连成一片的，两个人数的块数却不一样：

- 老周数出 3 块。他把斜着对角挨着的黑点也算成一块，还说两块都贴着图片边缘时“外面是通的”，也并成一块。
- 小林数出 6 块。她只认上下左右挨着，对角不算；两块各自贴边，她也不合并。

两个人谁都觉得自己数得对，吵了一轮也没结果。后来决定不靠眼睛拍板：口径按 README 定死（四连通、对角不算、图像外不算连通），结果再用 `samples/expected/` 里的编号图和统计表逐行核对。以后再遇到“数出来不一样”的图，先对口径，再对数。
